Timetable+ is an Android app that can be used to simplify scheduling and room management on college campuses. 
Timetable+ assists teachers in locating free rooms and labs through a systematic time-slot system. 
The application uses a 3D array to maintain scheduling information to ensure precise tracking of availability. 
Timetable+ has an easy-to-use interface and user-friendly features, making it easy to handle timetables, making it an asset to schools.
